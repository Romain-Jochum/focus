# Contributing

Focus is a personal app, published for reading, learning and forking. Issues and ideas are welcome. Open an issue before a pull request so we can agree on the change first.

The build needs only the Command Line Tools. Run `make test` before you submit. It must pass.

- New behaviour goes in `FocusCore`: pure, Foundation only, with time passed in through `Tick`. Add a scenario test in `Tests/FocusTests/EngineTests.swift`.
- Keep `docs/design.md` and `README.md` in sync with the code.
- The session budget holds: at most 3% CPU and under 200 MB. Re-measure with `make probe` after any sensor or cadence change.
- Privacy: nothing leaves the Mac. Never write camera frames or screenshots to disk.
- No LaunchAgent or background helper. Focus runs only while it is open.
- The phone model is generated by `scripts/make-model.sh` and is never committed.
