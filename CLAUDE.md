# Focus

macOS focus app (Swift 6 in Swift 5 language mode, SwiftPM, macOS 26, Command Line Tools only). `README.md` covers install and use; `docs/design.md` is the source of truth for behaviour and every threshold. Keep both in sync with code changes.

- `make test` runs the checks in well under a second; `make install` builds, signs and installs to `~/Applications`. For parallel or private builds use `SWIFT_BUILD='swift build --scratch-path .scratch/<name>'`.
- `FocusCore` stays pure and deterministic (Foundation only, time passed in through `Tick`). New behaviour goes there, with a scenario test in `Tests/FocusTests/EngineTests.swift`.
- Budget during a session: at most 3% CPU and under 200 MB. Re-measure with `make probe` after any sensor or cadence change.
- Privacy: nothing leaves the Mac; never write camera frames or screenshots to disk, except the false alarms kept by the opt-in developer mode (`false-alarms/`).
- Runs only while open: no LaunchAgent or background helper (by design).
- The phone model is generated by `scripts/make-model.sh` and never committed.
